# Gym Coach

Web app personale per seguire la scheda PPL + Upper/Lower in palestra:

- video degli esercizi della sessione corrente (YouTube)
- chat per registrare ogni serie (carico, ripetizioni, RIR) scrivendo o dettando
- consigli sul carico basati su RIR target 2–3 e double progression
- timer di recupero, archivio delle sessioni, backup/import
- domande libere al coach tramite chiave gratuita Gemini (opzionale, salvata solo sul dispositivo)

Tutti i dati restano nel browser del telefono (localStorage).
